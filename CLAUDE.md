# Working in this repo

- Repo: `git@github.com:HenRuw/ScoreSpace.git`, branch `main`.
- Commit and push as normal part of the workflow — don't wait to be asked
  each time. Small, atomic, logical commits with clear imperative-mood
  subject lines (and a body when the *why* isn't obvious from the diff).
  Don't bundle unrelated changes into one commit.
- Still never force-push, `reset --hard`, amend published commits, or delete
  branches without explicit confirmation — those stay off-limits regardless.
